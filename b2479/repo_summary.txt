OSRSTracker 是一个专门为 Old School RuneScape (OSRS) 玩家设计的个人游戏数据追踪平台，旨在帮助玩家便捷查看自身技能统计数据及游戏内经济信息。

该项目主要解决OSRS玩家获取和可视化个人游戏数据的需求，通过简单的命令即可获取指定玩家的技能统计信息并在网页上展示。同时计划开发经济功能，用于查询游戏内物品的市场趋势和价格信息。

技术栈方面，项目采用 Python 作为后端语言，使用 Flask 框架构建 Web 服务，前端使用 HTML 和 CSS 实现页面展示，通过 Docker 进行容器化部署，数据存储采用 JSON 格式。平台支持英语和西班牙语两种语言，提供多语言界面。

使用方法简单，通过 Makefile 命令即可构建和运行网站，访问 http://localhost:8080/ 查看效果。
